# GitHub-Python-Repository

Python practice projects. Several applications and programs coded with Python while I learn.
I come from IBM Mainframe development (COBOL, CICS, DB2) and I am moving into Python and AI automation.

- **Guess the number:** simple 5/10 question game to guess a random number.
- **Higher or lower:** simple game asking you to guess who has the most followers.
- **Coffee Machine:** coffee machine simulator.
- **Quiz project:** question and answer game.
- **Turtle games:** drawing with the Turtle module and an automatic turtle race game.
- **Snake game:** classic snake game (turtle, classes and inheritance).
- **Pong game:** classic two-player ping pong (turtle, classes).
- **Turtle crossing game:** cross the street, avoid the cars, use space to advance.
- **Pomodoro timer:** a study timer using the pomodoro method, made with Tkinter.
- **Password manager:** creates, saves and searches passwords (Tkinter, JSON). Learning exercise, passwords are stored as plain text.
- **Flash cards:** made with Tkinter, helps you learn French words.
- **IsOverYourHead:** sends you an email when the ISS is over your head, uses an API.
- **KanyeWestQuotes:** gets quotes from an API, Tkinter interface.
- **Trivia game:** upgrade of the Quiz project, gets questions from an API, Tkinter interface, OOP.
- **Stock news alert:** compares a stock's last two closing prices and fetches news (Alpha Vantage, NewsAPI, Twilio). Keys are placeholders.
- **Workout tracking:** logs exercise written in plain text into a Google Sheet (Nutritionix, Sheety). Keys are placeholders.
